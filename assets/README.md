# CV/Resume Files

Place your CV/Resume files in this folder with one of these names:

## Recommended file names (in order of preference):
1. `EhiByte_CV.pdf` (PDF format - most professional)
2. `EhiByte_Resume.pdf` 
3. `cv.pdf`
4. `resume.pdf`
5. `EhiByte_CV.docx` (Word document format)
6. `EhiByte_Resume.docx`
7. `cv.docx`
8. `resume.docx`

## Instructions:
1. **Save your CV** in PDF format (recommended) or Word format (.docx)
2. **Rename the file** to one of the names above (preferably `EhiByte_CV.pdf`)
3. **Copy the file** into this `assets` folder
4. The download button will automatically work with your actual CV file!

## File Format Recommendations:
- **PDF**: Best for professional use, maintains formatting across all devices
- **DOCX**: Good if recruiters need to edit or parse your CV
