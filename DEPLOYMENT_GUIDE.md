# 🚀 GitHub Pages Deployment Guide

## ✅ **Your Portfolio is Now on GitHub!**

## 🌐 **Enable GitHub Pages**

Follow these steps to make your portfolio live:

### Step 1: Go to Repository Settings
1. Visit: https://github.com/Ehis-cyber/ehibyte
2. Click the **"Settings"** tab (top right of repository)
3. Scroll down to **"Pages"** in the left sidebar

### Step 2: Configure Pages
1. Under **"Source"**, select **"Deploy from a branch"**
2. Choose **"main"** branch
3. Select **"/ (root)"** folder
4. Click **"Save"**

### Step 3: Wait for Deployment
- GitHub will build your site (takes 1-2 minutes)
- You'll see a green checkmark when ready
- Your live URL will be: **https://ehis-cyber.github.io/ehibyte**
